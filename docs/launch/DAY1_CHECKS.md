## A4 — one clean-Mac session and optional real recording

Download from https://presstalk.app/de/download.html on the test Mac. Do not
clear a working user's preferences or keychain to manufacture a fresh install.
Record whether it is an unused Mac or a new profile, and the limitations.

1. Record model, macOS version, app version and downloaded ZIP hash. Unzip,
   move to Applications and open normally. Record any prompt or warning exactly.
   Do not bypass a signature/damage warning to call the path passed.
2. Observe Microphone, Input Monitoring and Accessibility requests. Deny one
   deliberately, confirm useful guidance, then allow it through System Settings.
3. Observe first model download, its progress/error state, and whether quitting
   once and relaunching allows setup to finish. Record download time separately
   from speaking/insertion time. A fast existing model cache is not this test.
4. Open an unsent Mail draft or local text note. Use a sentence from an actual
   recurring task, without private recipient/customer information. Hold physical
   Fn, speak, release and record whether text arrives in the focused field.
   Clipboard-only recovery is recorded separately. Include every correction.
5. Try the same sentences with the current tool. Count corrections and total
   effort; do not generalize one person's result to German speakers generally.
6. After setup, disconnect all network routes and dictate in a local note.
   Record the outcome. Do not label Wi-Fi-off as offline if Ethernet remains.
7. Confirm the trial starts after the first successful dictation, persists after
   relaunch, and later stops new dictation on expiry. Never change the machine's
   system clock or destroy existing licence state. If natural expiry has not
   happened yet, record it as pending with the due timestamp (three days later).
8. Perform the test purchase/licence entry/offline-relaunch step from A1 when
   available. A screenshot of checkout before paying is not this evidence.

Optional 25–40 second recording: show the empty draft, physical Fn action,
natural German sentence, actual recognition wait, result and corrections. Use a
sentence such as “Donnerstag um zehn passt mir. Ich schicke dir die Notizen vor
unserem Gespräch.” This is a demonstration example, not a benchmark. Keep the
result unchanged and the dictation at actual speed. Caption tested hardware,
macOS, app version and any editing. Ask permission before publishing a tester's
voice; Alex's authorized product demo can be published under the standing brief.
