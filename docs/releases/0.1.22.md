# PressTalk 0.1.22

Holding the dictation key now records through an input-only AUHAL bound to the
selected microphone. This fixes the observed missing/truncated capture when
AirPods were the system default while a USB microphone was selected. PressTalk
never changes the system default input, and an unavailable selected microphone
produces a clear error instead of silently selecting another device.

- Retain the first audio buffer before showing Listening, drain conversion at
  release, and reject interrupted or incomplete capture before recognition.
- Treat an empty primary recognition as no speech when optional Whisper is not
  loaded. Silent holds return to Ready; real capture/model errors remain errors.
- Keep Settings behind the application receiving dictation. Wrap error messages.
- Use automatic language detection for every installation and remove the picker.
- Repair startup permission guidance, stale model-warming status, explicit
  Settings privacy buttons, and restarting the same installed app.
- Refresh microphone choices when the menu opens and apply shortcut changes
  safely while idle.
